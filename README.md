
# 🍕 Pizzería Mamma Mia

Aplicación web desarrollada con React y Vite para gestionar pedidos de pizzas, con autenticación de usuarios mediante JWT y conexión a una API.

### Funcionalidades
- Registro e inicio de sesión.
- Autenticación mediante JWT.
- Perfil de usuario y cierre de sesión.
- Catálogo de pizzas.
- Carrito de compras.
- Checkout protegido.

### Tecnologías
React · Vite · React Router · Context API · Bootstrap · JavaScript · JWT
