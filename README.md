# 🍕 Pizzería Mamma Mia — Hito 4

Aplicación web desarrollada con **React + Vite**, que permite visualizar pizzas consumidas desde una API REST.

### Tecnologías

- React
- Vite
- JavaScript
- Bootstrap
- CSS

### Funcionalidades

- Consumo de API de pizzas.
- Visualización del menú.
- Detalle de pizzas.
- Carrito de compras.
